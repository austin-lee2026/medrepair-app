# 天勤零件维修记录表

医疗器械零件维修情况在线记录与追踪系统，支持多人实时共享填写。

## 功能特性

- 📋 **完整记录** — 零件名称、维修人员、适用机型、故障描述、维修内容、维修难度、维修结果等10个字段
- 🚦 **红绿灯配色** — 已攻克(绿)、有进展(橙)、难度大(红)，状态一目了然
- ⏱ **自动时间戳** — 自动记录更新时间，仅内容有变动时才更新
- 📊 **统计面板** — 总记录数、各难度状态数量实时显示
- 🔍 **搜索筛选** — 支持关键词搜索，按难度/结果筛选
- 📤 **导出Excel** — 导出带红绿灯配色的Excel文件(.xls)
- 📥 **导入导出JSON** — 数据备份与恢复
- ☁️ **在线共享** — 部署后多人实时同步，无需导入导出

## 本地运行

### 1. 安装依赖

无需安装依赖，使用 Node.js 内置模块。

### 2. 启动服务

```bash
node server.js
```

默认端口 3000，也可通过环境变量指定：

```bash
PORT=8080 node server.js
```

### 3. 访问

浏览器打开 `http://localhost:3000`

## 在线部署

### 部署到 Render.com

1. Fork 或克隆本仓库
2. 登录 [Render.com](https://render.com)
3. 新建 Web Service，连接 GitHub 仓库
4. 配置：
   - **Build Command**: 留空
   - **Start Command**: `node server.js`
   - **NODE_VERSION**: 16 或更高
5. 点击 Deploy，等待部署完成

部署后获得公网地址，如 `https://tianqin-repair.onrender.com`，分享给同事即可多人同时使用。

## 数据结构

| 字段 | 说明 |
|------|------|
| 零件名称 | 必填 |
| 维修人员 | 必填 |
| 适用机型 | 如 Philips Brilliance 64排CT |
| 故障描述 | 故障现象说明 |
| 维修内容 | 维修过程与结果 |
| 维修难度 | 已攻克 / 有进展 / 难度大 |
| 难度备注 | 难度详细说明 |
| 维修结果 | 已修复 / 部分修复 / 待跟进 |
| 备注 | 其他说明 |
| 更新时间 | 自动记录，仅内容变动时更新 |

## 技术栈

- 前端：纯 HTML/CSS/JS 单文件，无外部依赖
- 后端：Node.js (http, fs 内置模块)
- 数据存储：JSON 文件 (data.json)
